# Allure Setup for Playwright Framework

This guide explains how to configure and integrate Allure Reporting in this Playwright framework in a simple, step-by-step way.

## 1. Install required dependencies

Open the terminal in the project root and run:

```bash
npm install -D allure-playwright allure-commandline
```

If you want, you can also add scripts in `package.json` for easier usage.

## 2. Add Allure reporter in Playwright config

Update `playwright.config.ts` to include the Allure reporter.

```ts
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './tests',
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 1 : undefined,

  reporter: [
    ['list'],
    ['html', { open: 'never' }],
    ['allure-playwright'],
  ],

  use: {
    baseURL: 'https://www.saucedemo.com',
    trace: 'on-first-retry',
    screenshot: 'only-on-failure',
  },

  projects: [
    {
      name: 'chromium',
      use: { ...devices['Desktop Chrome'] },
    },
  ],
});
```

### What this does
- `list`: prints test results in console
- `html`: keeps the default Playwright HTML report
- `allure-playwright`: generates Allure result files in the `allure-results` folder

## 3. Add scripts in package.json

Update `package.json` with these scripts:

```json
{
  "scripts": {
    "test": "playwright test",
    "test:allure": "playwright test --reporter=line,allure-playwright",
    "allure:report": "allure generate allure-results --clean -o allure-report"
  },
  "devDependencies": {
    "@playwright/test": "^1.62.1",
    "allure-playwright": "^3.10.2",
    "allure-commandline": "^2.43.0"
  }
}
```

## 4. Run the test with Allure

Execute:

```bash
npx playwright test tests/auth/standard-login.spec.ts --project=chromium
```

or use the script:

```bash
npm run test:allure
```

This generates Allure result files under the folder:

```bash
allure-results/
```

## 5. Generate the Allure HTML report

Run:

```bash
npx allure generate allure-results --clean -o allure-report
```

or:

```bash
npm run allure:report
```

This creates a readable HTML report inside:

```bash
allure-report/
```

## 6. Open the report

You can open the generated report in a browser:

```bash
npx allure open allure-report
```

Or directly open the generated file:

```bash
allure-report/index.html
```

## 7. Optional: add environment details

If you want to show environment metadata in Allure, create a file such as `allure.properties`:

```properties
allure.results.directory=allure-results
allure.link.tms.pattern=https://your-jira.example.com/browse/{}
allure.link.issue.pattern=https://your-jira.example.com/browse/{}
```

## 8. Useful notes

- `allure-results` is the raw data folder generated by Playwright.
- `allure-report` is the final HTML report.
- It is recommended to keep both folders in the project root.
- You can combine Allure with existing Playwright HTML reports if needed.

## 9. Common command summary

```bash
npm install -D allure-playwright allure-commandline
npx playwright test --reporter=line,allure-playwright
npx allure generate allure-results --clean -o allure-report
npx allure open allure-report
```

## 10. Result

After the setup, every Playwright test execution will produce structured Allure data, and the HTML report will provide richer insights like test history, suites, categories, and execution trends.
